# MCP

MCP（Model Context Protocol）是 AI FullStack Workflow 中连接 AI Agent 与外部工具、数据和系统的标准协议。

本章节介绍：

- MCP 原理与核心概念
- 安装与环境准备
- MCP Server 与 Tools
- MCP 在开发工作流中的应用
- 企业最佳实践
- 常见问题

## 目录

- `01-overview.md` — MCP 概述
- `02-install.md` — 安装与环境准备
- `03-server-and-tools.md` — MCP Server 与 Tools
- `04-workflow.md` — MCP Workflow
- `05-best-practice.md` — 最佳实践
- `06-faq.md` — FAQ

## 阅读建议

1. 先读 `01-overview.md` 建立整体认知。
2. 按 `02-install.md` 完成环境准备。
3. 参考 `03-server-and-tools.md` 理解 MCP 架构。
4. 按 `04-workflow.md` 建立 MCP 开发流程。
