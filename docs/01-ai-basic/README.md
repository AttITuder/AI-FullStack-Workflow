# AI 基础章节

> 本目录是知识库的第一章，为后续所有工具、Prompt、Agent 内容奠定认知基础。

---

## 章节简介

AI 基础章节回答一个根本问题：**AI 为什么改变软件开发，以及开发者如何应对这种改变**。本目录不教具体工具安装，也不罗列命令，而是从工程实践视角建立整体认知，让读者理解后续章节中每个工具和概念"为什么存在"。

如果把整本知识库比作一座建筑，本目录就是**地基**——地基不稳，后面学习 OpenCode、MCP、Agent 都容易迷失方向。

## 学习目标

完成本章学习后，你应该能够：

1. 说出软件开发四个范式的演进脉络及各自特点。
2. 解释 AI 为什么从底层改变软件生产的组织方式。
3. 定义"AI FullStack Workflow"的概念与核心组成。
4. 说出 AI 在需求、架构、编码、测试、审查、运维各环节的作用与边界。
5. 列出 AI 开发者需要具备的六大能力。
6. 客观认识 AI Coding 的优势与局限，知道如何用工程手段规避风险。
7. 了解 OpenCode、Codex、Claude Code、CodeBuddy、PI Agent 的基本定位。
