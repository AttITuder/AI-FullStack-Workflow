# Codex 安装与环境准备

> 面向实际开发者的环境准备指南。以稳定可复现为原则，不绑定具体版本号。

---

## 为什么需要了解

Codex 提供多种使用方式（ChatGPT 环境、CLI、IDE 集成），理解各自的形态与选择，是正确上手的第一步。本文覆盖使用方式概览、环境要求、安装流程、项目初始化与常见问题。

## 1. 使用方式概览

### ChatGPT 环境

- 在 ChatGPT 产品内使用 Codex 能力，无需本地安装。
- 适合快速体验、临时任务、云端批量执行。
- 优点：零安装、随用随走。
- 缺点：与本地项目/代码库的集成有限。

### Codex CLI

- 通过命令行在终端中使用 Codex。
- 面向开发者日常编码，可读取本地项目、生成与修改代码。
- 优点：贴近开发流程、可控性强。
- 缺点：需要安装与配置。

### IDE 集成

- 在 IDE（如 VS Code）中集成 Codex。
- 结合编辑体验与 Agent 能力。
- 优点：IDE 内完成交互。
- 缺点：依赖 IDE 与插件生态。

### 选择建议

| 场景 | 推荐方式 |
| --- | --- |
| 快速体验 | ChatGPT 环境 |
| 日常开发 | Codex CLI |
| 编辑器工作流 | IDE 集成 |

## 2. 环境要求

### 操作系统

- Codex CLI 主要支持主流桌面系统（macOS、Linux、Windows）。
- Windows 建议使用 WSL 获得完整终端体验。

### 开发环境

- 需要可用的终端环境。
- 建议具备常见开发工具链（Node、Python、Java 等，取决于项目）。

### Git

- 需要已安装并配置好的 Git。
- Codex 的部分能力依赖 Git 工作区（如提交、差异分析）。

### 账号

- 使用 Codex 需要 OpenAI 账号。
- CLI 与 IDE 集成可能需要 API 凭据或订阅。

### 验证环境

```bash
git --version
```

确认 Git 可用后，即可继续安装。

## 3. 安装流程

### CLI 安装

- 通过包管理器或官方脚本安装 Codex CLI。
- 安装命令以官方文档为准。

```bash
npm install -g @openai/codex
```

### 凭据配置

- 登录 OpenAI 账号或配置 API 凭据。
- 凭据通过环境变量或登录流程管理，避免硬编码。

### 验证安装

```bash
codex --version
```

出现版本号或帮助信息即安装成功。

## 4. 初始化项目

### 已有项目

- 在项目根目录使用 Codex。
- 让 Codex 读取项目结构，理解技术栈。

### 新项目

- 先初始化项目骨架（Git、目录结构、README）。
- 再使用 Codex 生成初始代码。

### 项目配置

- 在项目内补充规则与说明，约束 Codex 产出。
- 将团队规范纳入版本库，保持一致性。

## 5. 第一次使用流程

### 启动

在项目目录启动 Codex，确认能读取当前项目。

### 基本交互

- 提出一个简单任务（例如"解释项目结构"），验证链路。
- 让 Codex 生成一个小改动，检查产出质量。
- 运行测试，确认改动不影响现有功能。

### 首次自检清单

- [ ] 版本命令正常输出
- [ ] 账号/凭据配置生效
- [ ] 能读取当前项目文件
- [ ] 能完成一次简单任务

## 6. 常见安装问题

### 权限问题

**现象**：全局安装失败，提示无权限。

**处理**：配置 npm 全局目录为用户可写路径，避免使用 `sudo`。

### 网络问题

**现象**：安装或连接超时。

**处理**：

- 检查网络与代理设置。
- 必要时配置镜像源。
- 确认能访问所需服务。

### 凭据问题

**现象**：鉴权失败或未登录。

**处理**：

- 重新登录账号。
- 检查凭据环境变量是否正确导出。
- 确认账号有对应权限。

### 环境变量问题

**现象**：命令找不到、配置不生效。

**处理**：确认命令在 `PATH` 中，重载 shell 配置后重试。

## 最佳实践

1. 明确使用方式：快速体验用 ChatGPT，日常开发用 CLI。
2. 凭据走环境变量或登录管理，不写入仓库。
3. 新项目先搭骨架再让 AI 生成。
4. 团队统一安装与配置步骤，写入 README。

## 常见问题

**Q1：需要 OpenAI 订阅吗？**

取决于使用方式，CLI 可能需要 API 凭据或订阅，以官方说明为准。

**Q2：能在离线环境用吗？**

不能，Codex 依赖云端能力。

**Q3：CLI 和 ChatGPT 环境能力一样吗？**

形态不同，CLI 更贴近本地项目开发。

## 本章总结

- 三种使用方式：ChatGPT 环境、CLI、IDE 集成，按场景选择。
- 环境要求：主流系统、Git、账号/凭据。
- 安装流程：CLI 安装 + 凭据配置 + 验证。
- 常见问题集中在权限、网络与凭据三类。
