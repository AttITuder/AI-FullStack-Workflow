# Flutter Agent 工作流程

## 流程总览

```text
需求 → 分析 → 设计 → 生成 → 自检 → 交付
```

## 1. 需求分析

- 明确页面/功能的目标
- 确认技术栈与架构约束
- 输出任务拆解清单

## 2. 设计

- 确定数据模型与接口
- 确定状态管理与路由
- 输出文件结构

## 3. 生成

- 按模块生成代码（controller / binding / view / model）
- 复用统一封装（网络层、路由、通用组件）

## 4. 自检

对照验收清单逐项检查：

- [ ] 代码可编译运行
- [ ] 遵循 Clean Architecture 分层
- [ ] 命名规范统一
- [ ] 无硬编码、无重复代码
- [ ] 错误处理完整

## 5. 交付

- 说明新增/修改的文件
- 说明需要执行的命令（如 `flutter pub get`）
- 提示后续注意事项

## 场景响应

| 任务 | 动作 |
| --- | --- |
| 生成页面 | 按 generate_page prompt 流程执行 |
| 修 Bug | 定位根因 → 修复 → 补充测试/说明 |
| Review | 按 review 规范给出结构化意见 |
| 重构 | 先给方案，确认后再动手 |
